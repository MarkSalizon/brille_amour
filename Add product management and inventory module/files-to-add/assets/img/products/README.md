# Sample product images

`sample-designs.png` was generated with the built-in image generation tool. These are illustrative mockups, not photographs of actual inventory. Customer cards display “Sample design”; package descriptions define the actual inclusions.

Generation prompt: Create one product photography sprite sheet for a printing and personalized crafts shop, exactly five columns and four rows with each product contained in its cell. Warm ivory studio backgrounds, soft shadows, blush pink, sage and gold details, photorealistic tabletop mockups, no readable text or watermarks. Row 1: business cards, flyers, trifold brochures, posters, stickers. Row 2: packaging labels, invitations, printed T-shirt, floral mug, birthday paper party kit. Row 3: anniversary mugs and card, Valentine mug and photos, graduation mug and tags, Mother's Day mug and card, Father's Day mug and card. Row 4: wedding stationery, proposal poster and photos, baby shower stationery, Christmas mugs and gift tags, spare floral stationery. Keep compositions separated for CSS background positioning.

The name-to-cell mapping is in `includes/product_images.php`. Unknown product names retain their letter artwork.
